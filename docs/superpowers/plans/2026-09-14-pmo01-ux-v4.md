# PMO01 UX v4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn PMO01 into one coherent learning journey where the final case belongs to M01 and the home screen drives the learner to one next action.

**Architecture:** Refactor existing enhancement code instead of adding a new dashboard layer. Keep simulator/validation internals compatible, but change learner-facing framing and enrich the simulator review with deterministic after-action feedback derived from the existing four decisions.

**Tech Stack:** Vanilla HTML/CSS/JavaScript, LocalStorage, Node.js test runner.

**Spec:** `docs/superpowers/specs/2026-09-14-pmo01-ux-v4-design.md`

## Global Constraints
- Keep `#/mission/m01`, `pm01-sim-m01-v1`, treatment id `m01-mission-partner-launch-v1`, mission version `1`, decision ids/effects, and validation gates unchanged.
- No telemetry or network calls.
- Preserve company contexts small / medium / large.
- Preserve lesson completion logic.
- Learner-facing term is `Итоговый кейс M01`, not mission/simulation/post-case as a primary concept.
